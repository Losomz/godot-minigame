# 微信广告模板使用说明

本模板基于 `minigame4.5.1` 增加微信小游戏广告桥接层。Godot 端无需直接调用微信 `wx.createRewardedVideoAd` 等 API，只需要通过 `JavaScriptBridge` 获取 `GODOTSDK`，再调用模板注入的广告方法。

## 模板新增内容

广告桥只在 Godot 引擎分包中加载。`godot-sdk` 先创建 `GODOTSDK`，广告桥随后注入广告方法，最后才启动 Godot：

```js
// engine/game.js
import './godot-sdk'
import './godot'
import './wx-ad-bridge'

GODOTSDK.startGame(exe, pack)
```

新增文件：

```text
engine/wx-ad-bridge.js
```

根 `game.js` 保持默认职责，只加载微信适配层和 `godot-loader`，不会重复加载广告桥。

广告桥会向 `GODOTSDK` 注入以下方法：

```js
GODOTSDK.dsWxAdSetEventCallback(callback)
GODOTSDK.dsWxAdDebugState()
GODOTSDK.dsWxAdShowRewarded(adUnitId)
GODOTSDK.dsWxAdShowInterstitial(adUnitId)
GODOTSDK.dsWxAdShowCustom(adUnitId, left, top, width)
GODOTSDK.dsWxAdHideCustom()
```

## Godot 侧获取 GODOTSDK

```gdscript
var godot_sdk: Object = JavaScriptBridge.get_interface("GODOTSDK")
if godot_sdk == null:
    push_warning("GODOTSDK 不可用，请确认当前运行在微信小游戏导出环境。")
    return
```

## 注册广告事件回调

广告结果通过 JS 回调返回 Godot。建议用 JSON 字符串接收事件。

```gdscript
var _ad_callback: Object = null
var _godot_sdk: Object = null

func _ready() -> void:
    _godot_sdk = JavaScriptBridge.get_interface("GODOTSDK")
    if _godot_sdk == null:
        return

    _ad_callback = JavaScriptBridge.create_callback(Callable(self, "_on_wechat_ad_event"))
    _godot_sdk.dsWxAdSetEventCallback(_ad_callback)
    _godot_sdk.dsWxAdDebugState()

func _on_wechat_ad_event(args: Array) -> void:
    if args.is_empty():
        return

    var payload_text: String = str(args[0])
    var event: Variant = JSON.parse_string(payload_text)
    if not (event is Dictionary):
        return

    var event_dict: Dictionary = event as Dictionary
    print("微信广告事件：", event_dict)
```

常见事件字段：

```text
type: rewarded / interstitial / custom / bridge
stage: create / show / close / error / load / debug 等
ok: true / false
adUnitId: 广告位 ID
errCode: 微信错误码，可选
errMsg: 微信错误信息，可选
isEnded: 激励视频是否完整看完，仅 rewarded close 常用
```

## 显示激励视频广告

```gdscript
func show_rewarded_ad() -> void:
    if _godot_sdk == null:
        return
    _godot_sdk.dsWxAdShowRewarded("adunit-你的激励视频广告位")
```

激励视频关闭事件示例：

```gdscript
func _on_wechat_ad_event(args: Array) -> void:
    if args.is_empty():
        return

    var event: Variant = JSON.parse_string(str(args[0]))
    if not (event is Dictionary):
        return

    var data: Dictionary = event as Dictionary
    if str(data.get("type", "")) == "rewarded" and str(data.get("stage", "")) == "close":
        var completed: bool = bool(data.get("isEnded", false))
        if completed:
            print("完整观看，发放奖励")
        else:
            print("中途关闭，不发奖励")
```

## 显示插屏广告

```gdscript
func show_interstitial_ad() -> void:
    if _godot_sdk == null:
        return
    _godot_sdk.dsWxAdShowInterstitial("adunit-你的插屏广告位")
```

插屏关闭事件：

```text
type=interstitial stage=close ok=true
```

## 显示/隐藏原生模板广告

```gdscript
func show_custom_ad() -> void:
    if _godot_sdk == null:
        return
    _godot_sdk.dsWxAdShowCustom("adunit-你的原生模板广告位", 0, 0, 350)

func hide_custom_ad() -> void:
    if _godot_sdk == null:
        return
    _godot_sdk.dsWxAdHideCustom()
```

原生模板常见事件：

```text
type=custom stage=load ok=true
type=custom stage=error ok=false errMsg=...
```

## 注意事项

1. 广告位 ID 必须使用微信后台创建的对应类型广告位，并且通常以 `adunit-` 开头。
2. 激励视频必须以用户主动操作触发，完整观看后才发奖励。
3. 插屏广告可能受微信频控限制，频控错误不一定代表接入失败。
4. 若 Godot 侧获取不到 `GODOTSDK`，请确认运行的是微信小游戏导出产物，而不是普通编辑器环境。
5. 若 `GODOTSDK` 存在但没有 `dsWxAdShowRewarded` 等方法，请确认 `engine/wx-ad-bridge.js` 存在，并已被 `engine/game.js` 在 `godot-sdk` 之后 import。

## 推荐封装

模板只提供微信广告能力，不包含具体游戏业务。正式项目建议在 Godot 侧再封装一层广告系统，例如：

```text
业务 UI -> 项目广告系统 -> GODOTSDK.dsWxAdXXX -> 微信广告 API
```

这样业务层只关心“展示广告”和“广告结果”，不直接依赖 JS 方法名。
